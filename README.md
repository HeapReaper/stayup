# StayUp

## Description
A low-resource usage uptime monitor with incidents, subscribers and more!

## Stack
- **Full stack framework:** NextJS
- **Workers:** Go
- **Database:** SQLite

## Resources usage (expected, still in development)
- **NextJS:** 150MB
- **Go workers:** ~20MB
- **SQLite:** 0MB
